## Foodies 

## Our Purpose

With Fitness applications these days being complex, hard to follow, and littered with subscriptions.
Our team wanted to build a calorie tracker application with the goal of providing a **simple interface** that allows the user to track, and store calories within the palm of their hand.(No subscriptions needed)
