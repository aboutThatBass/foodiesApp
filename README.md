## Our Purpose

With Fitness applications these days being complex, hard to follow, and littered with subscriptions.
Our team wanted to build a calorie tracker application with the goal of providing a **simple interface** that allows the user to track, and store calories within the palm of their hand.(No subscriptions needed)

## How to Install Foodies
Due to the application not being available, you can download Foodies within our github repo. It would require the end user to have Java installed, so keep that in mind. 

## How to use Foodies.
Foodies will prompt you to create a new profile to both log in and keep track of the user calories. Then Foodies will prompt you summit the amount of calories per meal you ate daily, letting you know the remaining amount to reach your daily or weekly goal.
